# Техзадание: NoesDize — локальный конструктор сайтов

## Суть
NoesDize — веб-приложение, которое по нескольким вводным (название бизнеса, отрасль,
тон, тема оформления) детерминированно собирает из готовых блоков одностраничный
сайт с текстами, градиентами и скролл-анимациями и отдаёт его в виде одного
самостоятельного HTML-файла — без обращения к платным или внешним ИИ-сервисам.

## Пользователи и роли
| Роль | Что делает | Что видит |
| --- | --- | --- |
| Автор сайта (единственная роль, без регистрации и логина) | Заполняет мастер (название, отрасль, тон), выбирает тему оформления и набор секций, редактирует сгенерированные тексты, включает/выключает эффекты, сохраняет черновик, экспортирует HTML | Форму мастера, живой предпросмотр страницы в реальном времени, список своих сохранённых проектов (в браузере), кнопку экспорта |

## Функции MVP
| ID | Функция | Приоритет | Критерий приёмки |
| --- | --- | --- | --- |
| F1 | Мастер создания проекта | must | Пользователь вводит название бизнеса, выбирает отрасль из списка (≥6 вариантов) и тон (≥4 варианта: официальный, дружелюбный, дерзкий, минималистичный), нажимает «Создать» — открывается редактор с уже собранной страницей из секций «Hero», «О компании», «Услуги», «Контакты» |
| F2 | Библиотека блоков и управление секциями | must | В редакторе есть список из ≥8 типов секций (hero, о нас, услуги/фичи, преимущества, тарифы, отзывы, галерея-плейсхолдер, CTA, контакты, футер); пользователь может добавить секцию из библиотеки, удалить существующую, поднять/опустить её в списке — порядок и состав немедленно отражаются в предпросмотре |
| F3 | Локальная генерация текста по отрасли и тону | must | При смене отрасли или тона без перезагрузки страницы (без сети) тексты заголовков и абзацев в секциях пересобираются по локальным словарям и словарным шаблонам под выбранную комбинацию; в любой текстовое поле можно вписать свой текст вручную, и повторная генерация не перезаписывает изменённые вручную поля, пока пользователь явно не нажмёт «Перегенерировать» |
| F4 | Темы оформления | must | Пользователь выбирает одну из ≥6 готовых тем (палитра, пара шрифтов, светлый/тёмный режим); после выбора все цвета, фон и типографика в предпросмотре меняются одномоментно без перезагрузки страницы |
| F5 | Живой предпросмотр с адаптивностью | must | Панель предпросмотра обновляется без перезагрузки при любом изменении (текст, секции, тема, эффекты); в предпросмотре есть переключатель «десктоп / планшет / мобильный», при переключении ширина макета области предпросмотра меняется и содержимое остаётся читаемым без горизонтальной прокрутки |
| F6 | Визуальные эффекты с уважением к reduced motion | must | Есть переключатель «Эффекты вкл/выкл»; при включении секции получают анимацию появления при прокрутке, кнопки и карточки — плавные hover-переходы, hero — градиент или стеклянную поверхность; при системной настройке `prefers-reduced-motion: reduce` анимации появления отключаются автоматически даже если переключатель включён; при выключении переключателя вручную все анимации пропадают и это видно визуально |
| F7 | Экспорт в единый HTML-файл | must | Кнопка «Скачать сайт» отдаёт один `.html`-файл с инлайновыми CSS и JS (без внешних ссылок на CDN); открытый в браузере напрямую с диска файл выглядит идентично предпросмотру, включая выбранную тему и включённые эффекты |
| F8 | Сохранение и список проектов | should | Проект автоматически сохраняется в `localStorage` при любом изменении; на стартовом экране показан список ранее сохранённых проектов с названием и датой правки; открытие проекта из списка восстанавливает все секции, тексты, тему и настройку эффектов; есть кнопка «Удалить проект» с подтверждением |

## Модель данных
Все сущности хранятся локально в браузере (`localStorage`), сериализация — JSON.

**Project**
| Поле | Тип | Обязательное | По умолчанию |
| --- | --- | --- | --- |
| id | string (uuid) | да | генерируется при создании |
| name | string, 1–60 символов | да | — |
| industry | enum (см. `IndustryDictionary`) | да | «other» |
| tone | enum: formal \| friendly \| bold \| minimal | да | «friendly» |
| themeId | string, ссылка на Theme | да | «aurora-light» |
| effectsEnabled | boolean | да | true |
| viewport | enum: desktop \| tablet \| mobile (состояние UI, не влияет на экспорт) | нет | «desktop» |
| sections | Section[] | да, минимум 1 | [Hero] |
| createdAt | ISO datetime | да | текущее время |
| updatedAt | ISO datetime | да | текущее время |

**Section**
| Поле | Тип | Обязательное | По умолчанию |
| --- | --- | --- | --- |
| id | string (uuid) | да | генерируется |
| type | enum: hero \| about \| services \| features \| pricing \| testimonials \| gallery \| cta \| contacts \| footer | да | — |
| order | integer, уникален в рамках проекта | да | индекс добавления |
| title | string, до 80 символов | да | сгенерировано по F3 |
| body | string, до 600 символов | нет | сгенерировано по F3 |
| items | массив строк/пар (для services, features, pricing, testimonials, gallery-подписей), до 8 элементов | нет | сгенерировано по F3 |
| ctaText | string, до 40 символов | нет | «Связаться с нами» |
| isCustomText | boolean, признак ручного редактирования (защищает от перезаписи при регенерации) | да | false |
| visible | boolean | да | true |

**Theme** (статический локальный набор, не редактируется пользователем в MVP)
| Поле | Тип |
| --- | --- |
| id | string |
| name | string |
| mode | light \| dark |
| palette | { background, surface, text, primary, accent } — HEX |
| fonts | { heading, body } — имена системных/локально подключённых шрифтов |

**IndustryDictionary / ToneDictionary** — статические JS-объекты в коде приложения
(не сущности БД): наборы фраз-заголовков, шаблонов абзацев и списков услуг/тарифов
на отрасль и тон, из которых детерминированно (без случайности либо с посевным
псевдослучайным выбором на основе `project.id`) собираются тексты секций.

## Правила и валидация
- `name` обязателен, 1–60 символов, пустая строка блокирует кнопку «Создать» с подписью «Введите название».
- Нельзя удалить последнюю оставшуюся секцию — кнопка удаления у неё отключена с подсказкой.
- Нельзя добавить больше 12 секций — кнопка «Добавить секцию» скрывается с сообщением «Достигнут предел секций».
- Поля `title` и `body` обрезаются по лимиту символов на вводе; превышение лимита показывает счётчик красным и не даёт сохранить пустое обязательное поле.
- Экспорт (F7) недоступен (кнопка неактивна), пока в проекте нет ни одной видимой секции типа `hero`.
- При переключении отрасли/тона текст полей с `isCustomText = true` не перезаписывается; перезапись происходит только по явному действию «Перегенерировать всё» с подтверждением через диалог (необратимо для несохранённых правок).
- Ошибка чтения/записи `localStorage` (переполнение, приватный режим) показывает баннер «Не удалось сохранить локально» и не роняет редактор — работа продолжается в памяти вкладки.
- Название проекта должно быть уникальным среди сохранённых; при совпадении новому проекту автоматически добавляется суффикс «(2)», «(3)» и т.д.

## Состояния экранов

**Экран «Стартовый список проектов»**
- Пустое: нет сохранённых проектов — крупная кнопка «Создать первый сайт», короткая подсказка что делает приложение.
- Загрузка: короткий скелетон-список карточек на время чтения `localStorage` (доли секунды, но состояние предусмотрено).
- Ошибка: `localStorage` повреждён/недоступен — баннер с текстом ошибки и кнопкой «Создать новый проект» (список игнорируется, но приложение не падает).
- Обычное: карточки проектов с названием, датой правки, миниатюрой темы (цветной плашкой), кнопками «Открыть» и «Удалить».
- Много данных: больше 9 проектов — список становится прокручиваемым, сверху появляется строка поиска по названию.

**Экран «Мастер создания»**
- Пустое: все поля не заполнены, кнопка «Создать» неактивна.
- Загрузка: отсутствует как отдельное состояние — сборка происходит мгновенно на клиенте; вместо загрузки — сразу переход к редактору.
- Ошибка: не выбрана отрасль или тон — соответствующее поле подсвечивается и текст «Выберите значение».
- Обычное: все поля выбраны, доступна кнопка «Создать».

**Экран «Редактор + предпросмотр»**
- Пустое: только что созданный проект с одной hero-секцией и плейсхолдер-текстом — подсказка «Добавьте секции слева, чтобы собрать сайт».
- Загрузка: индикатор пересборки предпросмотра при регенерации текста для всего проекта (искусственно быстрая операция, но UI показывает спиннер на предпросмотре на время операции).
- Ошибка: попытка экспорта без hero-секции — тост «Добавьте секцию Hero перед экспортом»; ошибка сохранения — баннер, см. правила.
- Обычное: список секций слева с перетаскиванием порядка, панель настроек темы/эффектов, предпросмотр справа с переключателем viewport.
- Много данных: 10+ секций — список секций слева получает вертикальную прокрутку с фиксированной шапкой панели инструментов; предпросмотр остаётся прокручиваемым независимо.

## Принятые допущения
1. Расшифровать словосочетание «Noes Dize» из исходной фразы не удалось; трактую его
   как рабочее имя бренда, вероятно возникшее из искажённого при наборе/распознавании
   выражения «nice design». В спецификации и коде продукт называется **NoesDize** —
   это читаемый и произносимый вариант, сохраняющий узнаваемое звучание исходной фразы.
2. Внешних ИИ-сервисов и API-ключей нет и не будет: вся генерация текста, структуры
   и оформления сайта выполняется локально по статическим словарям и шаблонам,
   зашитым в код приложения; во время работы приложение не делает сетевых запросов.
3. Изображений и загрузки фото в MVP нет — вместо реальных фото используются
   декоративные CSS-градиенты, SVG-паттерны и однотонные плашки с подписями,
   чтобы не зависеть от внешних библиотек изображений.
4. Бэкенд не нужен: всё состояние (проекты, черновики) хранится в `localStorage`
   браузера пользователя; приложение — статический SPA-фронтенд, запускаемый одной
   командой (dev-сервер) без базы данных и серверной логики.
5. Готовый сайт экспортируется как один файл `.html` со встроенными `<style>` и
   `<script>` — это удобнее для «прокликать руками», чем ZIP-архив с несколькими
   файлами, и не требует серверной раздачи статики.
6. Список отраслей ограничен фиксированным набором из 6+ пунктов (например:
   кафе/ресторан, IT/стартап, салон красоты, магазин/e-commerce, услуги/консалтинг,
   образование, прочее) — этого достаточно, чтобы словарь текстов был осмысленным,
   без необходимости бесконечного покрытия всех ниш.
7. Chromium в окружении в этой версии не используется (например, для рендеринга
   миниатюр-превью в списке проектов) — миниатюрой служит цветная плашка темы;
   это дешевле и не требует серверного рендеринга headless-браузера.
8. «Качественность» и «красота» проверяются вручную по чек-листу: наличие тёмной
   темы, адаптивности, согласованной типографики и работающих скролл-анимаций —
   формальной метрики «красоты» не вводится, так как её нельзя прокликать как тест.

## Осознанно вне объёма
- Публикация/хостинг сайта на домене или через сторонний сервис — нет платного
  внешнего API для этого; пользователь скачивает HTML и размещает сам.
- Многостраничные сайты (несколько маршрутов/страниц) — MVP собирает одну
  посадочную страницу с якорной навигацией по секциям.
- Загрузка и обработка собственных изображений/логотипа — требует файлового
  хранилища или обработки на бэкенде, оставлено на будущую версию.
- Совместная работа нескольких пользователей над одним проектом — нет
  аккаунтов/бэкенда для синхронизации.
- Генерация текста через внешние ИИ-модели — прямо запрещено ограничениями
  окружения (нет ключей API).
- Редактирование произвольного HTML/CSS-кода секций («code mode») — усложняет
  валидацию и повышает риск сломанного экспорта, оставлено вне MVP.
- История версий/отмена-повтор (undo/redo) — достаточно автосохранения текущего
  состояния; полноценная история — доработка следующей версии.
- Пользовательские загружаемые шрифты — используются только системные/локально
  подключённые шрифты из готовых тем.

## Критерии готовности
- [ ] Приложение запускается одной командой и открывается в браузере без ошибок в консоли.
- [ ] Функции F1–F7 работают и проходят свои критерии приёмки при ручной проверке.
- [ ] Функция F8 (сохранение/список проектов) работает при ручной проверке.
- [ ] Ни один сценарий не обращается к внешним API или сети во время работы приложения.
- [ ] Для экрана списка проектов и экрана редактора реализованы все указанные состояния: пустое, загрузка, ошибка, обычное, «много данных».
- [ ] Доступна тёмная тема минимум для одной из готовых тем оформления.
- [ ] Экспортированный `.html`-файл открывается двойным кликом (`file://`) и выглядит идентично предпросмотру.
- [ ] Анимации отключаются при `prefers-reduced-motion: reduce` и переключателем эффектов.
- [ ] Макет остаётся читаемым и без горизонтальной прокрутки на десктопной, планшетной и мобильной ширине.
