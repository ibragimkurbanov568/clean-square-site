# КРАЙ — ролевая игра с открытым миром

Браузерная 3D-игра в жанре городской RP-жизни (вдохновлена мобильными RP-проектами и серией GTA, но всё своё: город, марки машин, интерфейс).
Промт-ТЗ — в [`PROMPT.md`](PROMPT.md). Первая версия одиночная, архитектура готовится к онлайну (состояние меняется командами — `src/sim/state.ts`).

## Что уже есть (веха 1)

- **Большой город Новоозёрск**:
  - сетка 13×13 кварталов, примерно 1.6×1.6 км;
  - районы: центр со сталинками, деловой квартал с высотками, спальные районы с панельками и дворами, хрущёвки, частный сектор, промзона, парки, площадь с мэрией;
  - за городом — река с набережной, лес и трассы на восток и юг.
- **Живой город**:
  - трафик ездит по полосам (правостороннее движение), соблюдает светофоры и держит дистанцию, сигналит;
  - пешеходы гуляют по тротуарам, переходят на зелёный по зебре, разговаривают, разбегаются от опасности;
  - у части прохожих — ники «игроков», в чате идут их сообщения и новости города.
- **Смена дня и ночи**: окна загораются выборочно, горят фонари, работают фары. Погода: дождь, мокрый асфальт с лужами.
- **Персонаж**:
  - создание: пол, кожа, причёска, цвет волос, одежда;
  - ходьба, бег, спринт, прыжок, удары;
  - 30 анимаций.
- **Машины**:
  - 9 моделей вымышленных марок (Волжанин, Кайдзен, Штальберг, Сеул-Моторс, Уралец);
  - физика Rapier: подвеска, привод, ручник, топливо, повреждения;
  - посадка и высадка, угон машин из трафика.
- **Работы**: курьер, грузчик в порту, таксист (с 2 уровня и с правами). У каждой работы 5 рангов.
- **Экономика**:
  - наличные и карта, банк;
  - автосалон и авторынок, АЗС, мэрия (права), гостиница, больница.
- **Розыск**:
  - звёзды за угон, наезд, драку, таран;
  - полиция едет по улицам и таранит;
  - арест (штраф и КПЗ); уйти от погони можно, если скрыться из виду.
- **Интерфейс**:
  - HUD, мини-карта с GPS-маршрутом;
  - телефон: карта, банк, работа, мои авто, профиль, настройки;
  - автосохранение.
- **Управление**: клавиатура и мышь, геймпад, сенсорный экран (джойстик и кнопки).

## Управление (ПК)

| Действие | Клавиши |
|---|---|
| Ходьба | WASD |
| Камера | мышь (клик — захват курсора) |
| Бег | Shift |
| Прыжок | Пробел |
| Удар | ЛКМ |
| Сесть / выйти из машины | F |
| Действие у двери | E |
| Телефон | P |
| Карта | M |
| В машине | W/S — газ и тормоз, A/D — руль, Пробел — ручник, H — сигнал, L — фары, C — камера |
| Пауза | Esc |

## Запуск и разработка

```sh
cd rp
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
npm test         # тесты (физика машины)
```

Ресурсы собираются из сырых CC0-файлов командой `RAW=/путь/к/raw npm run assets`. Источники и лицензии — в [`assets/LICENSES.md`](assets/LICENSES.md).
