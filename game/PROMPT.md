## 0. РОЛЬ И ГЛАВНАЯ ЗАДАЧА

Ты — ведущий геймдизайнер и старший разработчик браузерных игр. За плечами у тебя хиты
уровня Vampire Survivors, Brotato и Hades. Твоя задача — создать **законченную,
отполированную и затягивающую игру** в жанре roguelike-выживания в сеттинге тёмного фэнтези.

**Жёсткие требования к результату:**

1. Вся игра — **один файл `index.html`**: HTML, CSS и JavaScript внутри. Никаких внешних
   картинок, звуков, шрифтов, библиотек и CDN. Игра обязана работать офлайн, если открыть
   файл двойным щелчком.
2. Вся графика рисуется **процедурно** через Canvas 2D: фигуры, градиенты, частицы, тени.
   Весь звук синтезируется через **Web Audio API**.
3. Игра одинаково хорошо работает **на телефоне (сенсорное управление, вертикальный
   и горизонтальный экран) и на ПК (клавиатура, мышь, геймпад)**.
4. Стабильные **60 кадров в секунду** на телефоне среднего уровня при 300+ врагах на экране.
5. Код **чистый и модульный** внутри одного файла: разбит на логические секции
   с комментариями-заголовками. Никакого минифицированного месива.
6. Это **полная игра, а не прототип**: меню, обучение, прогрессия, баланс, сохранения,
   звук, настройки. Никаких заглушек, TODO и «здесь можно добавить».

Если что-то не помещается в один ответ, пиши код частями, но каждая часть должна

## 1. КОНЦЕПЦИЯ И КРЮЧОК

### 1.1. Лор (коротко, подаётся через экран загрузки и описания)

Солнце не взошло уже сорок лет. Мир поглотила **Вечная Ночь**, и из тьмы идут твари
Бездны. Последний свет в мире — **Священный Факел**, пламя, которое передают от одного
Хранителя к другому. Ты — очередной Хранитель. Тебе нужно продержаться до **рассвета**
(15 минут) и не дать Факелу погаснуть. Каждый выживший Хранитель приближает день,
когда солнце вернётся.

### 1.2. Уникальная механика — СВЕТ ФАКЕЛА

Этим игра отличается от десятков клонов Vampire Survivors:

- Вокруг игрока есть **радиус света**. За его пределами — почти непроглядная тьма.
- Враги в темноте видны только как **пары светящихся глаз**. Элитные враги и боссы
  светятся сами по себе.
- **Свет — это ресурс.** Он медленно угасает со временем. Его пополняют:
  - **Угли** (выпадают из врагов, работают как опыт и одновременно подпитывают факел);
  - **Масляные лампы** на карте (разбиваются, дают вспышку света и лечение);
  - некоторые пассивные предметы.
- Чем ярче факел, тем **больше радиус обзора и сбора, выше урон огнём**, но тем
  **агрессивнее и многочисленнее враги** (их привлекает свет). Это постоянный выбор
  между риском и наградой.
- Если свет падает до минимума, начинается **«Шёпот Бездны»**: экран темнеет по краям,
  слышен нарастающий шёпот, игрок получает периодический урон. Это напряжённо, но
  не смертельно мгновенно.
- **Вспышка** (активная способность, перезарядка 20 секунд): тратит 30% света, ослепляет
  и отталкивает всех врагов в радиусе, наносит урон. Кнопка на экране или пробел.

### 1.3. Главные эмоции, которые должна вызывать игра

- **Напряжение** — тьма вокруг, глаза в темноте, шёпот.
- **Всемогущество** — к 10-й минуте игрок выкашивает сотни врагов, экран горит.
- **«Ещё один забег»** — после смерти хочется сразу попробовать снова: новые
  разблокировки, новые комбинации.
- **Открытия** — секретные эволюции оружия, скрытые персонажи, тайные события.

## 2. ОСНОВНОЙ ИГРОВОЙ ЦИКЛ

### 2.1. Внутри забега (15 минут)

1. Игрок двигается. Атакует **автоматически** — оружие стреляет само.
2. Враги идут волнами со всех сторон, их становится больше и они становятся сильнее.
3. Из убитых врагов выпадают **угли** (синие, зелёные, красные, фиолетовые: 1/5/25/100 опыта).
4. Полная шкала опыта даёт **новый уровень**. Игра ставится на паузу, игрок выбирает
   **1 из 3 (или 4) карточек**: новое оружие, улучшение оружия или пассивный предмет.
5. Каждые 3 минуты приходит **элитная волна**, на 5, 10 и 14 минутах — **боссы**.
6. На 15:00 наступает **Рассвет**: катсцена восхода, победа, подсчёт награды.
   После победы можно продолжить в режиме **«Бесконечная ночь»** за бонусную награду.
7. Смерть — экран итогов и возврат в лагерь.

### 2.2. Между забегами (мета-прогрессия)

- За забег игрок получает **Пепел** (валюта мета-прогрессии).
- В **Лагере Хранителей** Пепел тратится на постоянные улучшения, персонажей,
  новые биомы и косметику.
- Прогресс сохраняется в `localStorage` автоматически.

## 3. УПРАВЛЕНИЕ

### 3.1. ПК

- **WASD / стрелки** — движение (8 направлений, диагональ нормализована).
- **Пробел** — Вспышка.
- **Esc / P** — пауза.
- **1/2/3/4** или клик — выбор карточки при повышении уровня.
- **Мышь** — только интерфейс. Прицеливание автоматическое.
- **Геймпад** (Gamepad API): левый стик — движение, A — Вспышка, Start — пауза,
  крестовина и A — навигация по меню.

### 3.2. Телефон

- **Плавающий виртуальный джойстик**: появляется там, где палец коснулся левой
  половины экрана (или любой точки — это настраивается), с мёртвой зоной 10%.
  Визуально — полупрозрачное кольцо и ручка.
- **Кнопка Вспышки** — справа внизу, большая (72px), с круговым индикатором перезарядки.
- **Кнопка паузы** — правый верхний угол.
- Лёгкая **вибрация** (`navigator.vibrate`) при получении урона, повышении уровня и
  убийстве босса. Отключается в настройках.
- Запрет прокрутки, масштабирования и выделения текста: `touch-action: none`,
  `user-select: none`, meta viewport с `user-scalable=no`, отключено контекстное меню.
- Поддержка «чёлки» и скруглённых углов: `env(safe-area-inset-*)`.
- При сворачивании вкладки (`visibilitychange`) игра автоматически встаёт на паузу.

### 3.3. Адаптивность

- Canvas на весь экран, учитывается `devicePixelRatio` (но не выше 2 ради
  производительности).
- **Одинаковая видимая область мира** на любом экране: масштаб камеры подбирается так,
  чтобы по короткой стороне всегда было видно примерно 720 игровых единиц.
- Интерфейс масштабируется через `clamp()` и относительные единицы.

### 7.3. Боссы (с полосой здоровья наверху экрана)

1. **5:00 — Мать Гнили** (гигантский слизень). Фазы: плевки кислотой веером →
   призыв червей → на 50% HP делится на две половины.
2. **10:00 — Безглазый Епископ** (летающий лич). Фазы: кольца из черепов с проходами →
   телепорт с оставлением ловушек → на 30% HP гасит весь свет на 5 секунд
   (виден только игрок и глаза врагов).
3. **14:00 — Пастырь Бездны** (финальный босс, огромный силуэт из тьмы).
   Фазы: руки из тьмы бьют по зонам с предупреждением-разметкой →
   «Затмение»: свет становится ресурсом выживания → последний рывок, когда босс
   гонится за игроком и всё сжимается.

У каждой атаки босса есть **чёткое визуальное предупреждение** (красная зона
заполняется 0,8–1,2 с). Смерть должна казаться справедливой.

### 7.4. Директор спавна

- Таблица волн по времени: какие типы появляются, с каким весом, минимальное число
  живых врагов на экране (от 15 на старте до 350 к 13-й минуте).
- Враги появляются **за границей экрана** по кольцу, чаще — по направлению
  движения игрока.
- Здоровье врагов растёт на 8% в минуту, урон — на 5%.
- Чем больше света у игрока, тем выше плотность спавна (до +40%).
- Враги, слишком далеко отставшие от игрока, **телепортируются** вперёд по ходу
  движения, а не удаляются, чтобы давление не пропадало.
- Особые события: «Рой» (кольцо летучих мышей смыкается вокруг игрока),
  «Шествие» (колонна скелетов проходит через экран), «Кровавая Луна» (1 минута,
  все враги красные и быстрее, но опыт ×2).

## 8. БИОМЫ (КАРТЫ)

Карта бесконечная, генерируется процедурно чанками вокруг игрока.
Декор детерминирован от seed: одни и те же координаты всегда выглядят одинаково.

1. **Проклятое Кладбище** (доступно сразу): надгробия, кресты, мёртвые деревья,
   туман. Масляные лампы на могилах.
2. **Утонувший Собор** (открыть: победить на Кладбище): колонны, витражные осколки
   на полу, вода по щиколотку (рябь от шагов). Уникальный враг — Утопший Хорист.
3. **Пепельные Пустоши** (открыть: победить в Соборе): трещины с лавой, пепел падает
   с неба, горячие зоны наносят урон, но дают +свет.
4. **Сердце Бездны** (открыть: победить в Пустошах): фиолетовая тьма, парящие
   обломки, гравитационные аномалии, притягивающие игрока. Финальный биом.

У каждого биома своя палитра, декор, фоновый эмбиент, модификатор
(например, в Пустошах свет угасает на 30% быстрее) и 2 уникальных врага.

## 9. МЕТА-ПРОГРЕССИЯ: ЛАГЕРЬ ХРАНИТЕЛЕЙ

Главное меню игры — это **Лагерь**: костёр в центре, вокруг палатки-разделы.
Анимированный огонь, искры, звук потрескивания.

### 9.1. Разделы лагеря

1. **Алтарь Пепла** — постоянные улучшения за Пепел (у каждого 5 уровней,
   цена растёт: 100, 250, 500, 1000, 2000):
   Сила, Броня, Здоровье, Регенерация, Скорость, Область, Длительность, Перезарядка,
   Удача, Магнетизм, Рост опыта, Жадность (+Пепел), Свет, Воскрешение (1 ур.),
   Реролл (+1 перевыбор карточек за уровень), Пропуск, Изгнание (убрать вариант
   из пула до конца забега).
   Кнопка **«Вернуть весь Пепел»** — бесплатный сброс.
2. **Зал Хранителей** — выбор и открытие персонажей.
3. **Карта Ночи** — выбор биома и сложности.
4. **Кодекс** — энциклопедия: все оружия, предметы, враги, эволюции
   (неоткрытое — силуэтом с «???»). Процент заполнения.
5. **Летопись** — статистика: лучшее время, всего убийств, всего забегов,
   любимое оружие, суммарное время в игре.
6. **Испытания** — 40+ достижений с наградами (Пепел, персонажи, косметика).
   Примеры: «Убить 100 000 врагов», «Победить без пассивов», «Победить, не опуская
   свет ниже 50%», «Открыть все эволюции», «Продержаться 5 минут без движения».
7. **Ежедневная Ночь** — одинаковый для всех забег дня: seed от даты, заданные
   персонаж, биом и модификаторы. Результат в виде текстовой карточки с эмодзи
   копируется в буфер обмена (как в Wordle):
   ```
   🔥 Последний Факел — Ночь #142
   ⏱ 15:00 ☀️ РАССВЕТ
   💀 4 812 убито
   ⚔️ Меч Рассвета · Коса Жнеца
   🟧🟧🟧🟧🟥⬛
   ```

### 9.2. Сложность

- **Сумерки** (лёгкая) — враги −30% HP, свет угасает медленнее.
- **Полночь** (нормальная).
- **Кошмар** (открывается после первой победы) — враги +50% HP, +25% скорости,
  Пепел ×2.
- **Проклятия** (как «Жар» в Hades): после победы на Кошмаре открываются 10
  переключаемых модификаторов, каждый добавляет % к награде.

## 10. ИНТЕРФЕЙС И ЭКРАНЫ

### 10.1. Список экранов

1. **Заставка при загрузке** — логотип с дрожащим пламенем, «Нажмите, чтобы начать»
   (нужно для разблокировки аудио на iOS).
2. **Лагерь** (главное меню).
3. **Выбор персонажа → выбор биома → выбор сложности** — один экран с тремя шагами.
4. **Игровой HUD.**
5. **Выбор улучшения** при повышении уровня.
6. **Открытие сундука.**
7. **Пауза**: продолжить, настройки, текущий билд (иконки и уровни), сдаться.
8. **Смерть / Рассвет** — итоги.
9. **Настройки.**
10. **Обучение** — при первом запуске: 4 коротких подсказки прямо в игре,
    без отдельного экрана с текстом.

### 10.2. HUD

- Сверху: шкала опыта во всю ширину, уровень, **таймер** по центру (крупно),
  счётчик убийств и собранного Пепла.
- Под опытом — иконки оружий и пассивов с уровнями (мелко, 2 ряда).
- Слева вверху: **шкала света** в виде стилизованного пламени.
- Здоровье — тонкая полоса прямо под персонажем (как в Vampire Survivors)
  и дублируется в HUD.
- Индикаторы за краем экрана: стрелки к сундукам, лампам и боссу.
- Всплывающие цифры урона (крит — крупнее и золотые). Отключаются в настройках.

### 10.3. Карточки улучшений

- 3 карточки (4 при высокой удаче). Каждая: иконка (процедурная), название,
  уровень («НОВОЕ!» или «Ур. 3 → 4»), понятное описание изменения.
- Рамка по редкости: серая, синяя, фиолетовая, золотая (для эволюций).
- Кнопки **Реролл / Пропустить / Изгнать** со счётчиками.
- Анимация появления: карточки вылетают по очереди.
- Если все улучшения собраны, предлагаются **Золото** (Пепел) и **Курица** (лечение).

### 10.4. Экран итогов

Время, уровень, убийства, собранный Пепел (с анимацией подсчёта), таблица урона
по каждому оружию (урон, УВС, убийства), новые разблокировки, кнопки
«Снова», «В лагерь», «Поделиться».

### 10.5. Визуальный стиль интерфейса

- Палитра: глубокий чёрный `#0a0908`, пепельно-серый `#2b2622`, пергамент `#e8dcc4`,
  огненно-оранжевый `#ff7a1a`, угольно-красный `#b3261e`, мистический фиолетовый
  `#7b4fd6`, холодное золото `#d4a94a`.
- Шрифты — только системные, но с характером: для заголовков серифный
  (`Georgia, 'Times New Roman', serif`, капс, разрядка), для текста —
  `system-ui`.
- Рамки в виде кованого металла: двойные линии, уголки-ромбы (через CSS
  `border-image` с SVG data-URI или псевдоэлементы).
- Все кнопки больше 44×44px, с состояниями hover, active и focus (видимый фокус
  для клавиатуры и геймпада).

## 11. ГРАФИКА И «СОЧНОСТЬ» (JUICE)

### 11.1. Отрисовка

- **Освещение:** сначала рисуется мир, потом поверх — offscreen-canvas с тьмой,
  из которого «вырезаются» источники света (`globalCompositeOperation =
  'destination-out'` и радиальные градиенты). Источники: факел игрока (мерцает
  через шум), лампы, огненные снаряды, взрывы, светящиеся враги.
- **Спрайты** всех врагов, игрока, снарядов и предметов рисуются процедурно
  **один раз при загрузке** во offscreen-canvas (атлас), дальше только `drawImage`.
  Анимация ходьбы — 2–4 кадра с покачиванием и сжатием-растяжением.
- Враги при получении урона **вспыхивают белым** на 80 мс (заранее
  подготовленный белый вариант спрайта).
- **Частицы:** искры факела, пепел в воздухе, кровь или эктоплазма при смерти,
  следы огня. Пул на 2000 частиц.
- **Декор земли** рисуется в тайловый слой по чанкам и кэшируется.
- Виньетка по краям экрана, лёгкая зернистость (плёночный шум, опционально).

### 11.2. Отклик

- **Тряска экрана** при уроне, взрывах и шагах босса (с затуханием; отключается).
- **Хит-стоп** 30–60 мс при убийстве элиты или босса.
- **Отбрасывание** врагов при попадании.
- Угли **с магнитной анимацией** подлетают к игроку по кривой с ускорением.
- Повышение уровня: вспышка света, кольцо, «ЗВОН», замедление времени на 0,3 с
  перед паузой.
- Смерть босса: замедление, серия взрывов, дождь из углей, сундук падает с неба.
- Низкое здоровье: пульсирующая красная виньетка и учащённое сердцебиение.

## 12. ЗВУК (ТОЛЬКО WEB AUDIO API, БЕЗ ФАЙЛОВ)

### 12.1. Звуковые эффекты (синтез)

Для каждого оружия — свой звук. Взмах — отфильтрованный шум со спадом;
молния — квадратная волна с быстрым питч-сдвигом; взрыв — шум плюс низкий синус.
Также нужны: попадание, смерть врага (несколько вариаций), подбор угля (тон растёт,
если собираешь подряд, как в Vampire Survivors), повышение уровня (арпеджио),
открытие сундука (нарастающая мелодия), урон игроку, рёв босса, Вспышка,
шёпот Бездны (отфильтрованный шум с модуляцией), клики интерфейса.

**Ограничение:** не больше 8 одинаковых звуков одновременно и не больше 32 всего.
Небольшая случайная вариация высоты (±5%), чтобы не было «пулемётного» эффекта.

### 12.2. Музыка (процедурная)

- Генеративный эмбиент для каждого биома: низкий дрон, редкие колокольные ноты
  в минорном ладу (эолийский или фригийский), пэды через осцилляторы с
  фильтрами и ревербом (ConvolverNode с синтезированной импульсной характеристикой).
- **Динамическая интенсивность:** к 5, 10 и 14 минутам добавляются слои
  (барабаны из шума и синусов, бас, остинато). При боссе — отдельная, более
  агрессивная тема.
- Рассвет — светлая мажорная тема с колоколами.
- Лагерь — тихая тема у костра с «гитарными» щипками (Karplus-Strong).

### 12.3. Микшер

Отдельные громкости: общая, музыка, эффекты. Компрессор на мастер-шине, чтобы
при сотне взрывов ничего не хрипело.

## 13. ПРОИЗВОДИТЕЛЬНОСТЬ (КРИТИЧНО!)

1. **Фиксированный шаг симуляции** 60 Гц с аккумулятором и интерполяцией
   отрисовки. Максимум 5 шагов за кадр, чтобы не было «спирали смерти».
2. **Пулы объектов** для врагов, снарядов, частиц, углей и всплывающих цифр.
   Никаких `new` в горячем цикле.
3. **Пространственная хеш-сетка** (ячейка 64 единицы) для столкновений
   и поиска ближайших врагов. Никаких проверок каждого с каждым.
4. **Структуры массивов** или плоские типизированные массивы для частиц и углей.
5. **Слияние углей:** если на земле больше 400 углей, дальние сливаются в один
   крупный.
6. **Отсечение:** рисуется только то, что попадает в экран с запасом.
7. **Автокачество:** если FPS держится ниже 50 две секунды, уменьшается число
   частиц, отключаются тени и шум, снижается разрешение слоя света.
   В настройках есть выбор качества: Авто, Низкое, Среднее, Высокое.
8. Никаких `shadowBlur` в горячем цикле, только заранее отрисованные свечения.
9. Скрытый счётчик FPS и числа объектов (включается в настройках или клавишей F3).

## 14. СОХРАНЕНИЯ И НАСТРОЙКИ

- **localStorage**, ключ `lastTorch.save.v1`, JSON с полем `version` и миграциями.
- Все операции с хранилищем — в `try/catch`. Если хранилище недоступно
  (приватный режим), игра работает, просто без сохранения, и один раз об этом сообщает.
- Автосохранение после каждого забега и изменения в лагере.
- **Сохранение посреди забега** при сворачивании страницы: состояние забега
  сериализуется, при следующем запуске предлагается «Продолжить ночь?».
- **Экспорт и импорт сохранения** строкой base64 (перенос между устройствами).
- Настройки: громкость ×3, язык (RU/EN), качество графики, тряска экрана,
  цифры урона, вибрация, режим джойстика (фиксированный / плавающий),
  сторона джойстика (для левшей), показ FPS, **режим для дальтоников**
  (другая палитра углей и опасных зон), уменьшение вспышек (эпилепсия),
  отключение инверсии от Банши, размер интерфейса (90–130%).

## 15. ЛОКАЛИЗАЦИЯ

Все тексты — в одном объекте `STRINGS = { ru: {...}, en: {...} }`. Язык

(описания предметов с короткой строчкой лора курсивом).

## 16. АРХИТЕКТУРА КОДА

Внутри одного `<script>` код разбит на секции в таком порядке:

```
// ==== 1. CONFIG & CONSTANTS ====   (все балансные числа в одном месте)
// ==== 2. STRINGS (i18n) ====
// ==== 3. UTILS ====                (math, rng с seed — mulberry32, шум, easing)
// ==== 4. SAVE SYSTEM ====
// ==== 5. AUDIO ENGINE ====
// ==== 6. INPUT ====                (клавиатура, касания, геймпад → единый вектор)
// ==== 7. SPRITE FACTORY ====       (процедурная генерация атласа)
// ==== 8. POOLS & SPATIAL HASH ====
// ==== 9. DATA: characters, weapons, passives, enemies, bosses, biomes, waves ====
// ==== 10. GAME SYSTEMS ====        (player, weapons, enemies, spawner, pickups,
//                                     light, particles, damage, leveling, bosses)
// ==== 11. RENDERER ====            (world, entities, lighting, fx, hud)
// ==== 12. UI / SCREENS ====        (DOM-оверлеи поверх canvas для меню)
// ==== 13. META (camp, unlocks, achievements, daily) ====
// ==== 14. MAIN LOOP & BOOT ====
```

**Принципы:**
- Данные отделены от логики: оружие, враги и предметы описаны декларативно
  (объекты с параметрами и функциями поведения).
- Меню и интерфейс — DOM-элементы поверх canvas (так проще сделать доступность
  и адаптивность); игровой мир и HUD — canvas.
- Простая машина состояний: `BOOT → CAMP → SELECT → RUN ⇄ (LEVELUP | CHEST | PAUSE) → RESULTS`.
- Никаких глобальных переменных, кроме одного пространства имён `Game`.
- `'use strict'`, современный JS (ES2020), без транспиляции.

## 17. БАЛАНС: ОРИЕНТИРЫ

- Первое повышение уровня — через ~10 секунд, к 1:00 — уровень 5–6,
  к 5:00 — ~20, к 15:00 — 55–70.
- Формула опыта до следующего уровня: `5 + (lvl-1)*10`, после 20-го уровня `+13`
  за уровень, после 40-го `+16`.
- Первый забег новичка без улучшений должен длиться **5–8 минут** и заканчиваться
  ощущением «почти получилось».
- Первая победа — примерно на **5–10-й попытке** при нормальной игре.
- Ни одно оружие не должно быть обязательным: минимум 4 разных билда способны победить.
- Эволюция — ощутимый скачок силы (×3–5 к эффективности), но позже 8:00.
- Выдача Пепла: смерть на 5:00 — ~150, победа — ~1200 (плюс множители сложности).
- Все числа — в `CONFIG`, чтобы баланс правился в одном месте.

7. **PWA-готовность:** `<meta name="theme-color">`, иконка через data-URI,
