# Последний Факел

Roguelike-выживание в тёмном фэнтези, собранное по промту из [`PROMPT.md`](PROMPT.md).
Вся игра — один файл [`index.html`](index.html): без внешних картинок, звуков,
шрифтов и библиотек. Работает офлайн, на ПК и на телефоне.

## Как играть

Откройте `index.html` в браузере (можно двойным щелчком).

- **ПК:** WASD / стрелки — движение, Пробел — Вспышка, Esc / P — пауза, 1–4 — выбор карточки.
- **Телефон:** плавающий джойстик, кнопка ✦ — Вспышка, ❚❚ — пауза.
- **Геймпад:** левый стик, A — Вспышка, Start — пауза, крестовина — меню.

## Что внутри

- 8 Хранителей (один секретный), 12 видов оружия по 8 уровней с эволюциями, 16 предметов.
- 20 видов врагов, элиты каждые 3 минуты, 3 босса с фазами (5:00, 10:00, 14:00).
- 4 земли, механика света факела, Шёпот Бездны, Вспышка.
- Лагерь: Алтарь Пепла, Кодекс, Летопись, 45 испытаний, Ежедневная Ночь с карточкой «Поделиться».
- 3 сложности и 10 проклятий, режим «Бесконечная ночь».
- Процедурная графика (Canvas 2D) и процедурный звук и музыка (Web Audio).
- Русский и английский, настройки доступности, экспорт и импорт сохранения.

## Разработка

Исходники разбиты по разделам в `src/`, а `build.sh` склеивает их в `index.html`:

```sh
./build.sh
```

Баланс правится в объекте `CONFIG` (`src/01-config-strings.js`).

## Как выложить бесплатно

- **GitHub Pages:** включите Pages для репозитория, игра будет доступна по адресу `.../game/`.
- **Netlify Drop:** перетащите папку `game` на app.netlify.com/drop.
- **itch.io:** загрузите `index.html` как HTML-игру.
